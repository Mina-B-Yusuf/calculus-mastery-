# Calculus Mastery

An offline-first pattern-recognition drill app for Calculus 1 & 2, built on *Calculus: A Complete Course* (Adams & Essex, 10th ed).

- `docs/` — the installable PWA (GitHub Pages serves this folder directly). Open `docs/index.html` via a static server, or enable GitHub Pages on this repo pointing at `/docs`.
- `study-guide/` — full prose chapter notes (definitions, theorems, worked examples, review problems with solutions) that the drill app's question bank was derived from.

276 micro-skills, 871 question archetypes across all 10 chapters (P, 1–9).
